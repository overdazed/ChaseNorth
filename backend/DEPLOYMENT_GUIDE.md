# Hostinger VPS Setup for ChaseNorth Backend

## What Your Backend Does:
- **Database**: Connects to MongoDB (user data, products, orders)
- **Payments**: Processes PayPal payments
- **Authentication**: Handles user login/registration
- **File Processing**: Generates PDFs, handles uploads
- **Business Logic**: Order processing, inventory management

## VPS Requirements:
- **RAM**: 1GB minimum (your app needs ~500MB+)
- **Storage**: 25GB+ (for uploaded images, logs)
- **Node.js**: Version 18+ required
- **24/7 Uptime**: Server must run continuously

## Cost Breakdown:
- **Hostinger VPS**: $3.99/month = ~€3.70/month
- **MongoDB Atlas**: $0-20/month (free tier available)
- **Domain**: Already paid
- **SSL Certificate**: Usually free with hosting

## Alternative Free Options:
1. **Railway** (railway.app) - Free tier for small apps
2. **Render** (render.com) - Free tier with sleep after inactivity
3. **Vercel** - Free for frontend, backend needs paid plan
4. **Heroku** - Free tier discontinued, now paid
